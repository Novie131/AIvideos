# 小橘 訓練資料集

**用途**：`pipeline-plan.md` §6.5 決策樹走到**方案 D**（LoRA 訓練）時的輸入。
現在不需要訓練，但**出圖時就要順手收**——§6.6 第 3 點：不要等到要訓練才回頭翻三集的檔案。

## 規約

每筆資料是**同名的一對檔案**：

```
0001.png     主圖，768x1344
0001.txt     caption
0002.png
0002.txt
```

臉部裁切放 `face/`，同樣同名對應：

```
face/0001.png    512x512
face/0001.txt
```

## caption 寫法

固定以觸發詞開頭，其後只描述**會變的東西**（場景、姿勢、光線、鏡位）。

```
xj_cat, sitting on a windowsill, warm afternoon light, medium shot
```

**觸發詞定為 `xj_cat`**（罕見 token，避免和既有概念打架）。

**不要**把 `character.json` 的固定外觀特徵寫進 caption。
理由：寫進去等於告訴模型「這些特徵是可變的描述」，模型就不會把它們吸收成觸發詞的固有屬性——
而讓 `xj_cat` 一詞就自動帶出右耳缺角和鈴鐺，正是訓練的全部目的。

## 收錄門檻

只收**右耳白色缺角與黃銅鈴鐺兩項都清楚可見**的圖。特徵糊掉的圖會稀釋訓練訊號，寧缺勿濫。

目標 25~40 張，涵蓋不同景別（特寫／中景／遠景）、姿勢、光線。

## 來源標註

每張圖必須能追溯到是哪個 preset 出的。檔名不夠用時，寫進 `manifest.jsonl`：

```json
{"file": "0001.png", "preset": "style-v1", "project": "ep002-egypt-30s", "shot": 3, "seed": 20260923}
```

**跨 preset 版本的圖不可混進同一次訓練**——風格不一致的資料集會訓出四不像。
