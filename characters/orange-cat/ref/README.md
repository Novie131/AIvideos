# 小橘 參考圖

## `hero.png` —— 定妝照

`pipeline-plan.md` §6.2 第 4 點要求的**所有方案共同輸入**。
方案 A（Qwen-Image-Edit）與 B（FLUX Kontext）都吃它當身分來源，
方案 E（去背疊圖）也從它衍生素材。**這張圖的品質決定整個角色 IP 的上限。**

規格：

- 正面、中景、中性背景
- `character.json` 的每一項特徵都清楚可見，尤其**右耳尖端白色缺角**與**黃銅小鈴鐺**
- 768x1344
- 同時另存 `hero_face.png`（512x512 臉部裁切）

定妝照一旦選定就**不要再換**。換掉等於換角色，之前所有集數的一致性基準全部失效。

## 產生方式

bake-off 之前先用暫定 checkpoint 大量抽，人工挑一張特徵最齊全的。
挑定後把當次的完整參數（含 seed）記進 `hero.json`，確保隨時能重現。
